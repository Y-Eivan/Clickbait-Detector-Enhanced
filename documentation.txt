NOTE TO CHANGE :

Methodology revision — sentiment feature extraction
Initial design used VADER (Hutto & Gilbert, 2014) for sentiment scoring of video transcripts and comments. Upon review, this approach was found incompatible with the dataset characteristics: the source corpus (Vierti channel, n ≈ 37k) contains a substantial proportion of Indonesian-language content, and VADER's lexicon-based approach is constrained to English vocabulary. Applying VADER to non-English text yields scores approaching zero regardless of actual sentiment polarity, introducing a systematic bias correlated with language rather than clickbait status — a confound that would compromise the validity of sentiment as a discriminative feature.
To address this, the sentiment extraction module was replaced with cardiffnlp/twitter-xlm-roberta-base-sentiment (Barbieri et al., 2022), an XLM-RoBERTa transformer fine-tuned on multilingual Twitter sentiment data spanning eight languages including English and Indonesian. This substitution offers three methodological advantages:

Language-agnostic operation: the model produces consistent sentiment estimates across the full dataset without requiring language-based filtering or routing, preserving sample size.
Richer feature representation: the model outputs probability distributions over three classes (positive, neutral, negative) rather than a single compound score, providing higher-dimensional sentiment features for downstream classification.
Established benchmark performance: XLM-RoBERTa-based sentiment models represent the current standard for multilingual sentiment analysis in NLP literature, providing stronger methodological grounding than translation-based or lexicon-based alternatives.

For compatibility with the existing feature pipeline, a continuous polarity score is computed as score = P(positive) − P(negative), approximating VADER's compound score on the [−1, +1] interval while retaining the underlying class probabilities as additional features.
